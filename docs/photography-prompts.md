# Product Photography Prompts — DALL·E 3

Twelve self-contained prompts for the GiftHub NG catalogue. Each is tuned to read as part of the same series — same direction, same surface, same light, same lens. The only thing that changes is what's in the hamper.

## How to use

1. In ChatGPT, prepend each prompt with:
   `Use this prompt exactly as written. Do not rewrite, rephrase, or shorten it.`
   (ChatGPT will otherwise silently re-write image prompts and break the series consistency.)
2. Request the **square (1024×1024)** aspect.
3. Save each as `/public/products/<slug>.jpg` using the slug listed under each prompt. (E.g. the first one becomes `public/products/campus-comfort-hamper.jpg`.)
4. After all twelve land, flip the `USE_CUSTOM_PHOTOGRAPHY` flag in `lib/mock-data.ts` from `false` to `true` — every product card site-wide swaps to the local image.

## House style (baked into every prompt below)

Overhead editorial flat-lay product photograph on a soft, slightly textured cream parchment surface. Warm late-afternoon Nigerian sunlight from the upper-left, casting soft directional shadows. Color palette: coffee brown, aged brass, parchment cream, with one product-specific accent. Style: editorial commercial product photography, shot on a 50mm lens at f/2.8, shallow depth of field with the main hamper sharp and the edges softly blurred. Mood: warm, premium, thoughtful. Square 1:1 aspect, ultra-detailed, high resolution. Do not include any text, logos, words, lettering, signage, watermarks, brand marks, or human figures anywhere in the image.
